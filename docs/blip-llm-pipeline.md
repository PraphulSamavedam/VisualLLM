# BLIP + LLM Pipeline Architecture

## Overview

The BLIP + LLM pipeline combines image captioning capabilities with large language models to perform Visual Question Answering (VQA). This approach leverages BLIP (Bootstrapping Language and Image Pre-training) to generate descriptive captions of images, which are then used as context for LLMs (Llama-2 or Mistral) to answer questions about the images.

## Component Details

### 1. BLIP Image Captioning

BLIP (Bootstrapping Language and Image Pre-training) is a flexible framework designed specifically for image captioning tasks. When provided with an image, BLIP outputs a descriptive caption by:

- Processing the input image through a patch embedding layer
- Using a transformer encoder to understand relationships between image patches
- Generating a word sequence through a language decoder

**Model Used**: BLIP-1 pre-trained on COCO dataset

**Example Output**:
- Input: Image of children sleeping
- Output: "Children are sleeping calmly in bed"

### 2. Prompt Construction

The pipeline constructs prompts by combining:
1. BLIP-generated caption
2. User's question
3. Specific instructions for answer format

### 3. LLM Processing

Two LLM variants are supported:
- **Llama-2-7b-chat-hf**: Meta's conversational model
- **Mistral-7B-Instruct-v0.2**: Mistral AI's instruction-following model

### BLIP + Mistral Implementation

```python
"""
Process images using BLIP captions and Mistral for VQA
"""
import pandas as pd
import torch
from transformers import pipeline
from tqdm import tqdm

# Load data
qa_data = pd.read_csv(sampled_qa_file_path)
captions_data = pd.read_csv(captions_file_path)
captions_data.drop(["Image file"], axis=1, inplace=True)
df = pd.concat([qa_data, captions_data], axis=1)

# Initialize Mistral pipeline
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

                       device=device,
                       torch_dtype=torch.bfloat16)
```

## Prompt Templates

The pipeline implements four different prompt configurations, progressively increasing in complexity:

### Configuration 1: Default (20 tokens)

**Purpose**: Baseline performance with minimal constraints

```python
df["Prompt"] = "Based on the image caption (generated by BLIP model): '" \
                + df["Generated Caption"] + "', Answer the question '" \
                + df["Question"] + "' \n Answer: "

answers = [{
    'Image ID': instance['Image ID'],
    'Caption': instance["Generated Caption"],
    'Question': instance['Question'],
    'Prompt': instance['Prompt'],
    'Generated Answer': llamaPipe(instance['Prompt'],
                                   max_new_tokens=20)[0]['generated_text']
} for _, instance in tqdm(df.iterrows())]
```

**Example**:
```
Based on the image caption (generated by BLIP model): 'Children are sleeping in bed',
Answer the question 'How many children are there?'
Answer:
```

## Data Flow

1. **Input Preparation**
   - Load question-answer pairs from sampled dataset
   - Load pre-generated BLIP captions
   - Concatenate dataframes for processing

2. **Model Initialization**
   - Set up device (CUDA/CPU)
   - Load LLM pipeline (Llama or Mistral)
   - Configure generation parameters

3. **Inference Loop**
   - For each image-question pair:
     - Retrieve BLIP caption
     - Construct prompt with specific template
     - Generate answer using LLM
     - Store results with metadata

4. **Output Storage**
   - Save results to CSV files
   - Maintain different files for each configuration
   - Preserve image ID, caption, question, prompt, and answer

## Strengths

1. **Descriptive Context**: BLIP captions provide natural language descriptions that capture the overall scene
2. **Simple Pipeline**: Straightforward architecture with only two main components
3. **Good for Scene Understanding**: Effective for questions about overall image content and atmosphere
4. **Fast Inference**: Minimal preprocessing required before LLM processing

## Limitations

1. **Numerical Questions**: Caption may not include specific counts
   - Example: "Children sleeping in bed" doesn't specify how many children
2. **Object Details**: May miss specific objects not central to the scene
3. **Spatial Relationships**: Limited ability to answer precise location questions
4. **Caption Quality Dependency**: Performance heavily relies on BLIP's caption accuracy

## Use Cases

**Best suited for:**
- Questions about scene description ("What is happening in the image?")
- Mood/atmosphere queries ("What is the emotion shown?")
- General content questions ("What type of room is this?")
- Activity recognition ("What are people doing?")

**Not recommended for:**
- Precise counting questions ("How many objects?")
- Detailed object detection ("What specific items are visible?")
- Spatial arrangement queries ("Where is object X relative to Y?")
