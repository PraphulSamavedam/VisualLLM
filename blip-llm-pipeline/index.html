    BLIP + LLM Pipeline Architecture¶

    Overview¶

    The BLIP + LLM pipeline combines image captioning capabilities with large language models to perform Visual Question Answering (VQA). This approach leverages BLIP (Bootstrapping Language and Image Pre-training) to generate descriptive captions of images, which are then used as context for LLMs (Llama-2 or Mistral) to answer questions about the images.

    Component Details¶

    1. BLIP Image Captioning¶

    BLIP (Bootstrapping Language and Image Pre-training) is a flexible framework designed specifically for image captioning tasks. When provided with an image, BLIP outputs a descriptive caption by:

    • Processing the input image through a patch embedding layer
    • Using a transformer encoder to understand relationships between image patches
    • Generating a word sequence through a language decoder

    Model Used: BLIP-1 pre-trained on COCO dataset

    Example Output: - Input: Image of children sleeping - Output: "Children are sleeping calmly in bed"

    2. Prompt Construction¶

    The pipeline constructs prompts by combining: 1. BLIP-generated caption 2. User's question 3. Specific instructions for answer format

    3. LLM Processing¶

    Two LLM variants are supported: - Llama-2-7b-chat-hf: Meta's conversational model - Mistral-7B-Instruct-v0.2: Mistral AI's instruction-following model

    Prompt Templates¶

    The pipeline implements four different prompt configurations, progressively increasing in complexity:

    Configuration 1: Default (20 tokens)¶

    Purpose: Baseline performance with minimal constraints

    df["Prompt"] = "Based on the image caption (generated by BLIP model): '" \
                + df["Generated Caption"] + "', Answer the question '" \
                + df["Question"] + "' \n Answer: "

answers = [{
    'Image ID': instance['Image ID'],
    'Caption': instance["Generated Caption"],
    'Question': instance['Question'],
    'Prompt': instance['Prompt'],
    'Generated Answer': llamaPipe(instance['Prompt'],
                                   max_new_tokens=20)[0]['generated_text']
} for _, instance in tqdm(df.iterrows())]

    Example: 

    Based on the image caption (generated by BLIP model): 'Children are sleeping in bed',
Answer the question 'How many children are there?'
Answer:

    Configuration 2: Token-Limited (3 tokens)¶

    Purpose: Restrict output length to improve answer quality

    generation_cfg_answers = [{
    'Image ID': instance['Image ID'],
    'Caption': instance["Generated Caption"],
    'Question': instance['Question'],
    'Prompt': instance['Prompt'],
    'Generated Answer': llamaPipe(instance['Prompt'],
                                   max_new_tokens=3)[0]['generated_text']
} for _, instance in tqdm(df.iterrows())]

    Configuration 3: Token-Limited + Prompt Restriction¶

    Purpose: Combine token limit with explicit single-word instruction

                + df["Question"] + "'\n Answer: "

generation_cfg_prompt_restriction_answers = [{

Answer in a single word the question: 'How many children are there?'

    Configuration 4: Enhanced Prompt (Best Performance)¶

    Purpose: Comprehensive instructions to ensure clean, single-word answers

    df["Prompt"] = "Based on the image caption (generated by BLIP model): '" \
                + df["Generated Caption"] + "'. Answer in a single word the question: '" \
                + df["Question"] + "' \n In plain simple English language without any emoticons or icons or font colors "\
                + "or punctuation marks. I strongly state do not repeat the question, prompt used, disclaimer, explanation" \
                + "or anything apart from answer, that is just provide the answer in a single word in lowercase, the question: '" \
                + df["Question"] \
                + "'. Remember if you are unable to answer the question based on the caption provided by BLIP, mention 'NA'.\nAnswer: "

prompt_with_generation_cfg_answers = [{

    Data Flow¶

    1. Input Preparation
    2. Load question-answer pairs from sampled dataset
    3. Load pre-generated BLIP captions

    4. Concatenate dataframes for processing

    5. Model Initialization

    6. Set up device (CUDA/CPU)
    7. Load LLM pipeline (Llama or Mistral)

    8. Configure generation parameters

    9. Inference Loop

    10. For each image-question pair:

      • Retrieve BLIP caption
      • Construct prompt with specific template
      • Generate answer using LLM
      • Store results with metadata

    11. Output Storage

    12. Save results to CSV files
    13. Maintain different files for each configuration
    14. Preserve image ID, caption, question, prompt, and answer

    Configuration Comparison (Mistral)¶

    Configuration Exact Match Semantic Match
    Default (20 tokens) 0.1288 0.1522
    Max 3 tokens 0.2159 0.2577
    Max 3 tokens + single word prompt 0.4293 0.5209

    Key Observation: Adding prompt-level restrictions significantly improves accuracy. The combination of token limiting and explicit single-word instruction achieves 3.3x better exact match accuracy compared to default configuration.

    Strengths¶

    1. Descriptive Context: BLIP captions provide natural language descriptions that capture the overall scene
    2. Simple Pipeline: Straightforward architecture with only two main components
    3. Good for Scene Understanding: Effective for questions about overall image content and atmosphere
    4. Fast Inference: Minimal preprocessing required before LLM processing

    Limitations¶

    1. Numerical Questions: Caption may not include specific counts
    2. Example: "Children sleeping in bed" doesn't specify how many children
    3. Object Details: May miss specific objects not central to the scene
    4. Spatial Relationships: Limited ability to answer precise location questions
    5. Caption Quality Dependency: Performance heavily relies on BLIP's caption accuracy

    Use Cases¶

    Best suited for: - Questions about scene description ("What is happening in the image?") - Mood/atmosphere queries ("What is the emotion shown?") - General content questions ("What type of room is this?") - Activity recognition ("What are people doing?")

    Not recommended for: - Precise counting questions ("How many objects?") - Detailed object detection ("What specific items are visible?") - Spatial arrangement queries ("Where is object X relative to Y?")

    CSV Output Format¶

    Each output file contains: - Image ID: Unique identifier for the image - Caption: BLIP-generated caption - Question: User's question - Prompt: Complete prompt sent to LLM - Generated Answer: LLM's response

    Comparison with Other Pipelines¶

    Pipeline Exact Match Semantic Match Best Use Case
    BLIP + Llama 0.4542 0.5927 Scene understanding
    YOLO + Llama 0.471 0.63 Object counting
    BLIP+YOLO + Llama 0.461 0.6423 Comprehensive VQA
    BLIP + Mistral 0.4293 0.5209 Scene understanding

    Analysis: While BLIP + LLM provides good baseline performance for descriptive questions, it's outperformed by YOLO-based pipelines for object-centric queries. The hybrid BLIP+YOLO approach achieves the best overall semantic match accuracy.

    Future Improvements¶

    1. Caption Enhancement: Fine-tune BLIP on VQA-specific captions
    2. Multi-Caption Generation: Generate multiple captions and use ensemble
    3. Question-Aware Captioning: Condition caption generation on the question
    4. Prompt Engineering: Explore additional prompt templates and strategies
    5. Model Scaling: Test with larger LLM variants (13B, 70B parameters)
